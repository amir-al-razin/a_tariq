* Project Title: Tariq - An Interactive Quranic Arabic Immersion App
* Course: CSE 4402: Visual Programming Lab

* Vision: A Sadaqah Jariyah project designed to help non-native learners understand Quranic Arabic natively, bypassing translation-heavy barriers.
Slide 2: Motivation & Problem Statement
* The Problem: Current Quranic apps focus heavily on isolated vocabulary and rote flashcards, leaving a massive gap in grammatical and syntactic understanding.
* The Translation Trap: Existing platforms force continuous translation to English or Bengali, preventing learners from thinking directly in Arabic.
* Why Esho Arbi Shikhi? Maulana Abu Taher Misbah’s book is a proven, highly structured masterpiece in Bangladesh that uses the "Direct Method" to transition learners to direct comprehension.
* SDG Alignment: Aligns with UN SDG Goal 4: Quality Education by democratizing high-quality classical Arabic learning.
Slide 3: Goals & Objectives
* Primary Goal: To digitize the complete learning journey of Esho Arbi Shikhi, making it an interactive, self-paced mobile application.
* Objective 1 (Curriculum Integrity): Implement the book’s exact sequential lessons and exercise patterns without altering its successful pedagogical flow.
* Objective 2 (Pronunciation & Reading): Build a solid foundation of correct pronunciation and unvoweled reading fluency.
* Objective 3 (Project Feasibility): Deliver a tested, high-quality Android prototype within the 8-week course timeline, while maintaining a long-term roadmap for post-course development.
Slide 4: Differentiation from Existing Solutions
* Traditional Apps (Duolingo, Kalaam, Quran Progress):
   * Rely on standard Modern Standard Arabic (MSA), translation drills, or isolated vocabulary lists.
   * Keep vowel marks (harakat) permanently turned on, creating an "illusion of fluency."
* Our Solution:
   * The Perfect Hybrid: We merge the proven, structured curriculum of a classical Madrasa textbook with the highly engaging, interactive UI mechanics of modern language apps.
   * Curriculum-Based Harakat Fading: Pre-programmed, sequential fading of vowels taken directly from the textbook as lessons progress.
   * Contextual Audio & Pronunciation Testing: Continuous learning loops backed by full audio reference and voice feedback.
Slide 5: Core Features & Pedagogy
* Duolingo-Inspired Gamified Exercises: Interactive learning through drag-and-drop sentence building, matching pairs, multiple-choice questions (MCQs), and bidirectional translation during the foundational lessons.
* Sequential Harakat Fading: Gradually hides vowel marks exactly as the author does in the book to transition users to reading unvoweled text.
* Interactive Comprehension Checks: Post-lesson prompts asking "Did you understand?" (hal fahimta?). If the user answers "No" (ma fahimtu), the app asks "Which part?" (ayyu juz'in) and uses AI to provide targeted explanations and redirects.
* Pronunciation Evaluator: A speech-to-text practice tool that allows users to recite specified phrases and receive immediate feedback on their pronunciation.
* AI Teacher Assistant & Lesson Redirect: A helper AI that analyzes mistakes and redirects the user to the exact previous lesson that resolves the issue instead of giving away answers.
* Quran Progress Integration: A visual Quran viewer where verses are highlighted only when the user has mastered both the vocabulary and syntax rules present in them.
Slide 6: Technical Tools
* Backend System: Java & Spring Boot for robust database schema, state management, and orchestration.
* Quranic Data & APIs:
   * Quran.com API: Utilized for fetching verified Quranic text, translations, tafsir, word-for-word morphology, and authentic audio recitations.
   * JQuranTree Java API: Used to natively parse and handle precise Arabic orthography, letters, and pre-programmed textbook diacritics.
* Frontend Mobile Client: Kotlin (Native Android) to achieve precise, pixel-perfect control over RTL (Right-to-Left) Arabic text rendering and interactive drag-and-drop mechanics.
* Web Portal: TanStack Start (or Next.js) for the desktop study interface and seamless state management.
* AI & Microservices (Python):
   * A lightweight Python microservice handling speech-to-text (STT) for pronunciation tests.
   * A RAG (Retrieval-Augmented Generation) pipeline in Python powering the AI Teacher Assistant for contextual explanations and accurate lesson redirections.
