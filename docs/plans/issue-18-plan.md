# Issue #18: Create Main Navigation Routes

## Objective

Setup TanStack Router file-based routing structure for all main screens in the web app. This establishes the navigation hierarchy matching the mobile app's screen structure: Home → Volume → Lesson → Chunk Engine.

TanStack Router uses file-based routing where each file in `src/routes/` becomes a route. Dynamic segments use `$paramName` syntax. The router auto-generates type-safe route definitions.

## Requirements

### Route Structure
Create the following route files:

1. **Home Route** (`/`)
   - File: `apps/web/src/routes/index.tsx`
   - Already exists - will be replaced with HomeScreen component in issue #19
   - For now, create placeholder that renders "Home Screen"

2. **Volume Route** (`/volume/$volumeId`)
   - File: `apps/web/src/routes/volume/$volumeId.tsx`
   - Dynamic param: `volumeId` (1, 2, or 3)
   - Placeholder: "Volume {volumeId} Screen"

3. **Lesson Route** (`/volume/$volumeId/chapter/$chapterId/lesson/$darsNum`)
   - File: `apps/web/src/routes/volume/$volumeId/chapter/$chapterId/lesson/$darsNum.tsx`
   - Dynamic params: `volumeId`, `chapterId`, `darsNum`
   - Placeholder: "Lesson {darsNum} Screen"

4. **Chunk Engine Route** (`/volume/$volumeId/chapter/$chapterId/lesson/$darsNum/chunk/$chunkId`)
   - File: `apps/web/src/routes/volume/$volumeId/chapter/$chapterId/lesson/$darsNum/chunk/$chunkId.tsx`
   - Dynamic params: `volumeId`, `chapterId`, `darsNum`, `chunkId`
   - Placeholder: "Chunk {chunkId} Engine"

### Route Params Validation
- Use TanStack Router's `validateSearch` for type-safe params
- Validate `volumeId` is 1, 2, or 3
- Validate `chapterId` and `darsNum` are positive integers
- Validate `chunkId` is a non-empty string

### Loading States
- Add `pendingComponent` to each route for loading UI
- Simple loading spinner or skeleton during navigation
- Use TanStack Router's built-in loading state management

### Navigation
- Routes should support browser back/forward buttons
- Use TanStack Router's `<Link>` component for navigation
- Type-safe navigation with route params
