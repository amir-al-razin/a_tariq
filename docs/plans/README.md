# Jules Plan Files

This directory contains implementation plans that Jules AI agents execute.

## Structure

Each plan file follows the format: `issue-{N}-plan.md`

Example: `issue-07-plan.md` for GitHub issue #7

## Plan File Format

Every plan must include:

1. **Issue metadata** - Issue number, title, branch names
2. **Files to modify** - Explicit list of files to create/update
3. **Files NOT to touch** - Explicit exclusion list
4. **Step-by-step implementation** - Detailed instructions
5. **Validation commands** - Commands Jules must run before PR

## Usage

Plans are generated by running `.claude/commands/plan.md` in your local IDE.

Jules reads these plans via the task prompt:
```
Read docs/plans/issue-07-plan.md and implement it exactly.
Follow all rules in AGENTS.md.
Branch from integration-sprint-1, branch name feat/issue-07.
Run all validation commands before opening PR.
Open PR to integration-sprint-1 when complete.
```

## Important

- Plans are the **source of truth** for Jules execution
- If the plan is wrong, fix the plan file — not the code after the fact
- Jules will NOT deviate from the plan
- Plans prevent hallucination by providing explicit context
