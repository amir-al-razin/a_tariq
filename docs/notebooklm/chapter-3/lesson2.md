This lesson emphasizes the transition from indefinite descriptive phrases to definite descriptive phrases (Sifah-Mawsuf with Al) and provides a clear breakdown of sentence structures (Tarkeeb).

### 1. Vocabulary & Core Grammar Progression
The lesson begins by demonstrating how adding "Al" (ال) changes the definiteness and structure of Sifah-Mawsuf (noun-adjective) phrases [1]:

*   **وَرْدَةٌ** (একটি গোলাপ - A rose)
*   **وَرْدَةٌ كَبِيْرَةٌ** (একটি বড় গোলাপ - A big rose) [Indefinite Sifah-Mawsuf]
*   **الوَرْدَةُ كَبِيْرَةٌ** (গোলাপটি বড় - The rose is big) [Mubtada-Khabar / Complete sentence]
*   **الوَرْدَةُ الكَبِيْرَةُ جَمِيْلَةٌ** (বড় গোলাপটি সুন্দর - The big rose is beautiful) [Definite Sifah-Mawsuf as Mubtada]
*   **عَجِيْبٌ** (আশ্চর্যজনক - Amazing/Strange)

### 4. Tarkeeb / Sentence Diagram Content
The lesson concludes with Exercise 4 (التَّمْرِيْنُ الرَّابِع), displaying grammatical diagrams (Tarkeeb) showing how an incomplete phrase (অপূর্ণ কথা) relates to a complete phrase (পূর্ণ কথা) [5]:

**Diagram 1: Object Descriptions**
*   `اَلْوَرْدَةُ الْكَبِيْرَةُ` (The big rose)
    *   اَلْوَرْدَةُ (Mawsuf / مَوْصُوْف) + الْكَبِيْرَةُ (Sifah / صِفَة) = অপূর্ণ কথা (Incomplete phrase).
*   `اَلْوَرْدَةُ كَبِيْرَةٌ` (The rose is big)
    *   اَلْوَرْدَةُ (Mubtada / مُبْتَدَأ) + كَبِيْرَةٌ (Khabar / خَبَر) = পূর্ণ কথা (Complete phrase).
*   `اَلْوَرْدَةُ الْكَبِيْرَةُ جَمِيْلَةٌ` (The big rose is beautiful)
    *   اَلْوَرْدَةُ (Mawsuf) + الْكَبِيْرَةُ (Sifah) = Together form the مُبْتَدَأ (Mubtada).
    *   جَمِيْلَةٌ = forms the خَبَر (Khabar).
    *   Result = পূর্ণ কথা (Complete phrase).

**Diagram 2: Proper Nouns with Titles**
*   `مَحْمُوْدٌ تَاجِرٌ` (Mahmud is a merchant) 
    *   مُبْتَدَأ + خَبَر = পূর্ণ কথা
*   `مَحْمُوْدٌ التَّاجِرُ` (The merchant Mahmud) 
    *   مَوْصُوْف + صِفَة = অপূর্ণ কথা
*   `مَحْمُوْدٌ التَّاجِرُ غَنِيٌّ` (The merchant Mahmud is rich)
    *   مَحْمُوْدٌ (Mawsuf) + التَّاجِرُ (Sifah) = مُبْتَدَأ (Mubtada).
    *   غَنِيٌّ = خَبَر (Khabar) -> পূর্ণ কথা.

**Diagram 3: Complex Matching**
*   `زَيْنَبُ مُعَلِّمَةٌ` (Zainab is a teacher) -> পূর্ণ কথা (Mubtada + Khabar).
*   `زَيْنَبُ الْمُعَلِّمَةُ` (The teacher Zainab) -> অপূর্ণ কথা (Mawsuf + Sifah).
*   `زَيْنَبُ الْمُعَلِّمَةُ امْرَأَةٌ طَيِّبَةٌ` (The teacher Zainab is a good woman)
    *   زَيْنَبُ (Mawsuf) + الْمُعَلِّمَةُ (Sifah) = مُبْتَدَأ (Mubtada).
    *   امْرَأَةٌ (Mawsuf) + طَيِّبَةٌ (Sifah) = خَبَر (Khabar).
    *   Result = পূর্ণ কথা (Complete phrase) [5].
