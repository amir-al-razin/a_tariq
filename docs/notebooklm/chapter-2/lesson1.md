### 3. General Questions (سؤال عام) using Hal (هَلْ)
These exercises teach yes/no questions designed merely for understanding, labeled by the author as "শুধু বোঝার জন্য, অনুশীলনের জন্য নয়" (Only for understanding, not for practice) [2]. 

*   **هَلْ هَذَا قَلَمٌ ؟** (Is this a pen?)
    *   **نَعَمْ .. هَذَا قَلَمٌ** (Yes.. this is a pen.)
*   **هَلْ هَذَا مِفْتَاحٌ ؟** (Is this a key?)
    *   **لَا .. هَذَا قُفْلٌ** (No.. this is a lock.)

This concept is further tested via conversational image prompts (Exercise 3), where students must ask questions like "هَلْ هَذَا إِبْرِيْقٌ ؟" (Is this a jug?) and answer based on the picture provided [6].

### 4. Special Questions (سؤال خاص) using A...am (أَ ... أَمْ)
This is the new structural concept introduced to ask targeted questions offering two specific choices [2].

*   **أَ قَلَمٌ هَذَا أَمْ مِفْتَاحٌ ؟** (Is this a pen or a key?)
    *   **قَلَمٌ** (A pen.)
*   **أَ مِفْتَاحٌ هَذَا أَمْ قَلَمٌ ؟** (Is this a key or a pen?)
    *   **قَلَمٌ** (A pen.)
*   **أَ مِسْطَرَةٌ هَذِهِ أَمْ قَلَمٌ ؟** (Is this a ruler or a pen?)
    *   **قَلَمٌ** (A pen.)
*   **أَ قَلَمٌ هَذَا أَمْ مِسْطَرَةٌ ؟** (Is this a pen or a ruler?)
    *   **مِسْطَرَةٌ** (A ruler.)
*   **أَ هَذَا قَلَمٌ أَمْ ذَلِكَ ؟** (Is *this* a pen or *that*?)
    *   **ذَلِكَ** (That.)
*   **أَ ذَلِكَ مِفْتَاحٌ أَمْ هَذَا ؟** (Is *that* a key or *this*?)
    *   **هَذَا** (This.)

*Note: The author links these Special and General question structures to their core Bengali meanings at the end of the lesson: "এটি কি চাবি?" (Is this a key?), "এটি কি কলম, না চাবি?" (Is this a pen, or a key?), and "কলম কি এটি, না সেটি?" (Is the pen this one, or that one?) [2].*
