# Local Android Build Setup

This project can build APKs locally without consuming Expo cloud build quota.

## One-time prerequisites (Linux)

1. Install JDK 17+
   - Ubuntu/Debian example: `sudo apt update && sudo apt install -y openjdk-17-jdk`
2. Install Android Studio (includes SDK/Platform tools)
3. Set environment variables in your shell profile (`~/.bashrc` or `~/.zshrc`):

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_HOME=$HOME/Android/Sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH
```

4. Reload shell:

```bash
source ~/.bashrc
```

5. Verify tools:

```bash
java -version
adb version
```

## Local build commands

From project root:

- Release APK:

```bash
pnpm android:apk:local
```

- Debug APK:

```bash
pnpm android:apk:debug:local
```

## Output paths

- Release APK: `android/app/build/outputs/apk/release/app-release.apk`
- Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`

## Notes

- The `android/` folder is ignored in git and gets regenerated by `expo prebuild`.
- If Android package name changes, regenerate with prebuild before assembling.
- Use cloud build (`eas build`) only when you need signed distribution artifacts from Expo infrastructure.
