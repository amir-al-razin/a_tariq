Tariq Arabic

Project Assessment, Market Analysis, and Technical Architecture

1. Market Positioning

The current market for Arabic learning apps is dominated by solutions like Duolingo, Kalaam, and Quran Progress. While accessible, they suffer from fundamental pedagogical flaws.

Feature Area Competitors (Duolingo, etc.) Tariq's Approach
Pedagogy Heavy translation drills (Arabic → English/Bengali). The "Direct Method". Think directly in Arabic without translation overhead.
Vocalization (Harakat) Permanent vowel marks; creates an "illusion of fluency." Sequential Harakat Fading based on curriculum progression.
Error Correction Binary Right/Wrong with correct answer revealed. AI-Teacher (hal fahimta? / ayyu juz'in) redirects to specific past lessons to bridge understanding gaps.
Quran Integration Isolated vocabulary flashcards loosely tied to verses. Curriculum-Gated Mus'haf. Verses "unlock" dynamically as the user masters the underlying syntax rules.

2. Technical Stack & Sustainability

Is Java / Spring Boot sustainable long-term?

For a Sadaqah Jariyah project meant to scale globally and manage complex user states and AI orchestrations, Java is an exceptionally strong long-term choice.

3. Book Pedagogy & Feature Architecture

Guiding Principle: We will strictly follow Maulana Abu Taher Misbah’s book. Not a single concept or flow from the book will be missed; everything is built strictly on top of its pedagogical foundation.

🎯 Sequential Harakat Fading & Engaging Exercises

Goal: Transform static textbook exercises into playful, dynamic digital experiences while honoring the book's exact vowel-fading mechanics.

  • Data Structure: Every vocabulary word and sentence from the book will be digitized with full harakat metadata.
  • Fading Algorithm: As the user completes lessons, specific vowel types (e.g., fatha, kasra, damma) are programmatically stripped from known words in subsequent exercises, forcing the user to rely on syntax rather than sight—exactly mirroring the book's pacing.
  • Playful Pedagogy: Standard translation drills will be replaced by rich drag-and-drop sentence building, auditory matching, and visual contextual puzzles that make the rigor of the book feel like a game.
📖 Gated Quran Mus'haf Visualization

Goal: Verses only become fully legible (highlighted or diacritics revealed) once the user learns the vocabulary and grammar.

  • Data Model (Spring Boot): The backend stores a UserMastery matrix containing rules and words acquired.
  • Rendering (React Native): The UI fetches a page of the Quran. For each word, it checks isMastered(word.root, word.grammarRule). If true, it renders clearly; if false, it is grayed out or blurred.
🤖 Gamified AI-Teacher Substitution

Goal: Diagnose exactly why a user made a mistake and redirect them, rather than just marking it wrong.

  • Implementation: When a user fails a drag-and-drop test, Spring Boot calls an LLM (via LangChain4j) passing the curriculum context. The LLM identifies the broken grammatical rule.
  • Action: The app navigates the user back to the specific mini-lesson for that rule, simulating a live teacher's intervention.
📚 Advanced Post-Curriculum Reading

Goal: Allow users to read unvoweled Hadith or scholarly texts with on-demand AI assistance.

  • Implementation: A specialized React Native text component handles long-form RTL text.
  • Interaction: Tapping a difficult word triggers a Spring Boot endpoint that uses the AI to provide instant morphological breakdown and I'rab (grammatical parsing) based on the sentence context.
